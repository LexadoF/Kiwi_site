# Configure logs

This subcommand will allow you to configure the logs system by specifying a channel in which the bot will send logs related to the server, this include, members joining and leaving, messages being edited and deleted, users being kicked or banned from the server, roles being added to a user and channels created or deleated.

## Usage

`/logs-configuration configure <channel>`

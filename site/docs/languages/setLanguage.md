# Set Language

This is the set language command, it allows you to switch the bot from using the default language (english) to another language, currently only spanish (ES) and english (EN) are supported, but this might change in the future.

## Usage

:::note

This command will only work in servers, if sending a command to the bot from dm's, the bot will reply based on your current locale (or english by default).

:::

`/set-language <language>`

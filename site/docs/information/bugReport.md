# Bug Report

This command allows you to send a bug report, remember to include as much details as possible so we can take a look into it.

## Usage

`/bug-report`

![bug report command 1](img/bugReportCommand1.png)

After executing the command, a modal will appear and there is where you can write the details of the bug, remember to include as much details as possible.

# User Info

This command will allow you to display information from a user (or yourself), this information include the roles the user have, their account creation date, etc.

## Usage

`/user_info {user}`

![user info command img](img/userInfoCommand.png)

### Optional parameter

* user: This parameter determines the user from which you want to see information, if not sent, the bot will display information about you.

# Eliminar

:::danger

Si ejecutas este comando, el sistema de bienvenidas será desactivado y kiwi no enviará mensajes de despedida. Si deseas restablecerlo, debes crear el sistema de bienvenidas denuevo.

:::

Este es el subcomando eliminar, puedes ejecutarlo con `/configurar-bienvenidas eliminar` , este subcomando te permitirá eliminar el sistema de bienvenidas.

## Uso

`/configurar-bienvenidas eliminar`

Solo basta con ejecutar el comando y el bot eliminará el sistema de bienvenidas.
![create command img](./img/welcomeCommandDelete.png)

:::note

Si no existe un sistema de bienvenidas para eliminar, el bot enviará un mensaje informando de esto, más no sucederá nada.

:::

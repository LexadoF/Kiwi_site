# Eliminar

:::danger

Si ejecutas este comando, el sistema de despedidas será desactivado y kiwi no enviará mensajes de despedida. Si deseas restablecerlo, debes crear el sistema de despedidas denuevo.

:::

Este es el subcomando eliminar, puedes ejecutarlo con `/configurar-despedidas eliminar`, con este puedes eliminar el sistema de despedidas.

## Uso

`/configurar-despedidas eliminar`

Solo basta con ejecutar el comando y el bot eliminará el sistema de despedidas.

![delete command img](./img/goodbyeCommandDelete.png)


:::note

Si no existe un sistema de despedidas para eliminar, el bot enviará un mensaje informando de esto, más no sucederá nada.

:::

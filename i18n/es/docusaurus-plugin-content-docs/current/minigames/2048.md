# 2048

Este es el minijuego 2048. El objetivo es alcanzar la ficha de 2048 combinando números iguales. Desliza las fichas por el tablero para fusionarlas y crear valores más altos. Continúa jugando hasta que alcances la meta o el tablero se llene.


## Uso

`/2048`

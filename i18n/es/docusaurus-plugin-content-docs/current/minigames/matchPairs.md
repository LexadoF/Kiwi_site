# Parejas

Este es el minijuego parejas. El objetivo es emparejar cada ficha con su pareja. Este minijuego no se puede perder por cometer errores, solo se pierde por tiempo de espera (al no interactuar con el tablero durante un minuto). Una vez que se hayan encontrado todos los pares, el juego terminará y te dirá cuántas fichas volteaste antes de completar el tablero.

## Uso

`/parejas`

# Tres en raya

Este es el minijuego de tres en raya. El objetivo es llenar una línea, ya sea vertical, horizontal o diagonal, antes que tu oponente. Este minijuego requiere dos jugadores para jugar. El jugador que envía el comando siempre será el primer jugador. El juego termina cuando uno de los jugadores completa una línea o cuando pasa un minuto sin ninguna acción.

## Uso

`/tres-en-raya <usuario>`

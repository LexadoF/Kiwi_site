# Documentación kiwi bot

Esta documentación te ayudará a entender y utilizar los comandos de Kiwi.

:::note

Se recomienda ejecutar /configurar-idioma y elegir el idioma con el que deseas que el bot responda. Actualmente, solo se soportan español e inglés, pero esto podría cambiar en el futuro.

:::

# Acerca de los parámetros

Si un comando tiene parámetros, los parámetros opcionales estarán entre `{}` mientras que los parámetros obligatorios estarán entre `<>`

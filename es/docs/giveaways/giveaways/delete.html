Delete giveaway

warning

This command will only work with active giveaways, if the giveaway is not active or the message is not a giveaway, the command will fail.

This subcommand will allow you to delete an active giveaway. For this you will need to provide the giveaway message id. If no valid giveaway is found in the message with the id given, you will get an error.

Usage​

/giveaways delete <message-id>

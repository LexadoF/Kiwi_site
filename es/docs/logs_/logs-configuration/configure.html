Configurar registros

Este subcomando te permitirá configurar el sistema de registros de auditoría especificando un canal al cual el bot enviará dichos registros, los cuales incluyen, miembros ingresando al servidor o abandonandolo, mensajes siendo editados o eliminados, usuarios expulsados o baneados del servidor, roles añadidos a un usuario y canales creados o eliminados

Uso​

/configurar-registros configurar <canal>

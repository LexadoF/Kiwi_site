8 Ball

This is the 8ball command, with it, you can get a random response from the magic ball

Usage​

/8ball <question>

Explanation​

This command has 1 required parameter, the responses it sends are random based on a pre set of answers, so you might get repeated answers after a while.

Required parameter​

  • question: This is the question you will like to ask to the magic ball (it has a limit of 500 characters)
